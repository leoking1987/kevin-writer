# 动笔前选择写法（script-angle 内置流程）

此流程只管选写法，成稿交回仓库根目录的 SKILL.md。适用：尚未指定写法的房产决策型口播与结构性改写。已指定写法、局部润色、审核和非房产内容直接成稿，不重复选。

## 资料与边界

筛写法前读取 [判断力方法论](methodology.md) 与 [十一种方法卡](method-cards.md)；需要转化预估时读 [E/F/G/H 规则](conversion-score.md)，记录选择时用 [台账模板](ledger-template.md)。先确认根目录写作规则与 [成交案例库](../transaction-cases.md) 的公开边界。

“逻辑清楚、信息密、说得顺、情绪有落点”、根目录观众利益与得失规则、事实与隐私规则优先。方法示例里的数字、客户对话和业绩不是真实素材；实际案例从成交库或用户资料取。汇总数字、31 笔逐笔价格与五笔详细案例都可独立引用，不能只允许汇总或强制同时讲过程。段落骨架是可用路径，不强制加案例、填满固定时码或加入 CTA。

## 1. 用本题的选择题确认任务

从原稿或上下文已能确定的变量直接跳过，不重复问。用户不必自己写“客户决定”或素材清单。缺失且会改变结论的变量，用当前环境的提问工具，或在对话中列选项，接受文字回复；工具题数上限优先。

第一轮按需要确认：主要受众（写到地区、价位或处境）、内容目标（咨询/传播/长期信任）、现有真实案例、拍摄条件。第二轮按需要确认：帮这群人决定什么（A 还是 B、现在做还是等、什么价格值得做）、两边担心的损失、目标片长、案例公开范围。每题 2–4 个来自本题的具体选项，推荐项放前面并说明理由；不能以通用人群标签替代具体受众。案例细节不逐项盘问，选定后列为待补，不为补模板编造。

尽量最多三轮：任务变量、决定变量、选写法。信息已齐就直接给菜单。跨了两类人或两件事，提供拆成两条的选项。纯历史或快报题可问是否包一层决策；用户选择保持原体裁就尊重。

把已有信息拼为一句：
> 这条内容要帮【受众】决定【决定】；开场呈现【损失】；主要靠【真实案例/数据】证明。

与选写法一起确认，不单独再多问一轮。

## 2. 筛出 2–4 种写法

先检查切口能否让主要受众看到自己的利益与代价，再筛叙事方法。不能让正确数据、名城、热门学校或高价房替代观众处境；菜单只有资料介绍、注意事项和泛泛建议时，先修切口。尊重用户已指定的题目与受众，不为追求情绪擅自换题，也不强迫观察体裁套二选一。

按方法卡的素材门槛筛选：缺真实劝退、原始预测存档或匿名分析授权等硬事实，不给相应卡。可补的非硬素材标“需补素材”，不伪装已具备。优先选最贴当前决定的卡；用户给了原稿时，把保持原稿写法作为一个对照选项。推荐项放第一位。

## 3. 展示完整预览卡

先列预览，再请用户选；不只给写法名称：

```text
【写法名】（推荐 / 需补素材）
一句话：观众看到什么样的片子
观众得失：想获得或保住什么；各条路径的价值与牺牲；真实依据
开场样稿：按 Kevin/Marie 的真实口吻写前两三句
骨架：5–8 段，每段一句目的＋大致时码
素材缺口：需要补什么（没有写“无”）
效果预估：
  开场抓力 高/中/低 —— 理由
  中段留存 高/中/低 —— 理由
  转化 约 N 分 —— E/F/G/H 分项与理由
  可信度风险 高/中/低 —— 最容易说过头的点
  制作负担 高/中/低 —— 拍摄、素材、录制
代价：选它要放弃什么
```

开场里的数字与事实只能来自本题已核验的素材；缺失用【待补】。转化分按包内 E/F/G/H 算，不把高分说成一定会带来客户。开场、留存、风险与制作负担是结构判断，在预览中写“留存为结构判断，尚无实测校准”，不给看似精确的概率。台账有可核验的相同写法记录时才引用。时码只是估算，不能为了节奏塞问题或反转。

## 4. 用户选择后交回写作流程

一次确认选定写法与一句话决定。用户改了决定，只重做受影响的候选；混合写法照用户要求执行，并解释代价。用户只要比较写法，就只交菜单，不擅自写全文。

将选定写法、主要决定、素材缺口交回根目录 SKILL.md：骨架以用户选定的为准，内容结构手册补节奏与平台包装，语言和案例规则仍遵守各自品牌。真实资料不足时标待补；不能写成可直接拍摄的完成稿。判断应写出两条路径的成立条件、代价与改判信号，不用“查资料/问专业人士/因人而异”代替答案。

## 5. 留下台账，不自动创建后续任务

在用户的写作项目中按 [台账模板](ledger-template.md) 追加日期、题目、候选、预估、选定写法和成稿编号；项目没有时可新建 `研究/写法台账.md`。安装目录不是写稿项目，不向 Skill 源文件存客户资料。

发布约 28 天后，有获授权的实测资料再回填平均观看比例、30 秒留存和线索信号评论。攒够 10 条再校准先验。此步骤不授权自动安排监控、联络其他任务、获取隐私数据或等待 28 天；没有数据就保持“未校准”。

## 不可绕过

- 买方/卖方与个人/团队角色准确，未经授权不公开可反查客户的细节。
- 已成交 DOM 不等于整体流动性，成交占比不等于偏好，个案不证明市场规律。
- 房产、法律、税务等时效事实遵守根目录事实门；不保证成交或收益。
- 一条内容一个主要决定；有真实承接才给一个主 CTA，没有就用判断收口。
