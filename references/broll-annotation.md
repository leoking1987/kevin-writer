# 视频脚本画面分析与 B-roll 策划规范

本规范只约束逐字稿完成后的画面分析流程，不规定文章题材、段落数量、叙事模板或 A-roll／B-roll 比例。每一篇先按内容自身需要写成独立文章，再分析画面承载方式。

## 一、必须遵守的顺序

### 1. 先写完整逐字稿

- 按主题、受众和素材本身组织文章，不预设固定段落结构。
- 写稿阶段不使用 A-roll、B-roll、镜号或画面占位来控制内容。
- 先把事实、逻辑、语气、节奏和作者判断写顺。

### 2. 锁定逐字稿

逐字稿通过事实门、Writing DNA、平台语域和保真润色后，再开始画面分析。口播或文章结构如果修改，后续画面分析必须重做。

### 3. 逐段分析画面承载方式

按自然段、句群或语义节拍逐段判断：

- A-roll：需要主持人出镜、直接表达、表情反应、现场讲述或段落连接。
- B-roll：用物件、房源、空间、资料、新闻、地图、数据、操作过程、环境或辅助人物活动更能说明内容。
- 混合：同一段前半句需要主持人，后半句适合切到画面；或旁白继续、画面切换。
- 画外旁白＋B-roll：口播连续，但画面不出现主持人。

判断依据是这段内容需要观众看见什么、听见谁、感受到什么。没有固定比例，也没有“必须 A-roll 主导”或“B-roll 只能点缀”的限制。全片可以是 A-roll、B-roll 或任意混合，由内容决定。

### 4. 在逐字稿副本上标注

- 使用 `[A-01 START]`／`[A-01 END]`、`[B-01 START]`／`[B-01 END]` 包住对应连续旁白。
- A-roll 不进入 B-roll 策划；B-roll 不写 Kevin、Marie 或其他主持人的正拍、反应、走路和讲解。
- 一个编号只包住一个连续口播区间；中间切回主持人或其他画面时，结束当前编号。

### 5. 单独策划 B-roll

只对第三步判定为 B-roll 的片段做策划。按编号顺序原样复制标注版中的对应旁白，再写完整画面。

## 二、B-roll 单独部分必写内容

- 编号
- 对应旁白：标注版逐字稿内同一段原文
- 叙事功能：举证、解释机制、展示空间、制造比较、呈现结果、承接情绪或推进动作
- 类型：实拍、房源、资料、新闻、地图、数据图、字卡、屏幕录制、生成或空镜
- 画面内容：镜头里实际出现什么
- 主体与动作：画面中的主体正在做什么，主体不得是 Kevin／Marie
- 空间关系：地点、前景／中景／背景、物件或辅助人物关系
- 景别／机位／运镜：特写／中景／全景、平视／俯拍／手持／固定、推拉摇移等
- 光线／材质／色彩：与内容相关的真实材质、时间、光线和色调
- 文字／数据：画面中的数字、来源、单位、日期及可编辑文字层
- 声音／音效：原声、现场声、拟音或留白
- 衔接：如何从上一画面进入、如何交给下一画面
- 来源／授权：自有、实拍、可商用素材、公开资料、生成用途或待补

## 三、交付格式

### 1. 全片逐字稿

干净版本，不加 A/B 标记或镜头规划。

### 2. 画面分析结果

按自然段或句群说明该段选择 A-roll、B-roll、混合或画外旁白＋B-roll，并写明依据。它不是新的文章结构，只解释画面为什么这样承载。

### 3. 标注版逐字稿

在完整逐字稿副本上加入 A/B 起止标记。

### 4. B-roll 单独部分

每条先列对应旁白，再列画面和执行信息。

## 四、示例

假设逐字稿里有一段：

> 门一打开，先是一段窄走廊，客厅的光在右边。这个停顿会让买家先感到空间被压住，再被光线拉过去。

画面分析可以有两种结论：

- 如果重点是 Marie 现场指出和感受，选 A-roll；
- 如果重点是让观众亲眼看到动线，选 B-roll。

本文不预设必须选哪一种。假如最终选择 B-roll，则可写成：

#### B-01

**对应旁白**

> 门一打开，先是一段窄走廊，客厅的光在右边。这个停顿会让买家先感到空间被压住，再被光线拉过去。

- 叙事功能：用真实动线说明买家第一眼的感受
- 类型：真实房源实拍
- 画面内容：固定机位对准玄关内侧，只出现门把手转动、门缝扩大和客厅光线进入，画面不出现主持人
- 主体与动作：门扇缓慢打开，明暗边界沿地面向玄关推进
- 空间关系：玄关在前景，窄走廊位于中景，客厅在右侧背景
- 景别／机位／运镜：玄关中近景固定，门完全打开后轻微前推
- 光线／材质／色彩：保留现场自然光，突出墙面、地面接缝和明暗变化
- 文字／数据：右下角显示“玄关—客厅连续动线”，独立可编辑字卡
- 声音／音效：真实开门声和室内环境声，不添加夸张转场音
- 衔接：由上一段口播进入开门动作，结束后回到下一段口播
- 来源／授权：本套房源实拍，正式制作时补真实文件与授权

## 五、质量要求

- 先用完整逐字稿检验文章本身，不能先画镜头再补旁白。
- 文章结构随题材变化，画面分析不能反过来把所有文章套成同一种骨架。
- 不预设 A-roll／B-roll 比例。视觉证据强的稿子可以大量用 B-roll，依赖人物表达和反应的稿子可以大量用 A-roll。
- 标注版中的每个 START 都必须有对应 END，并与 B-roll 策划编号一一对应。
- B-roll 部分的对应旁白必须原样复制标注版逐字稿，不能概括或同义改写。
- B-roll 不包含主持人；主持人出现的一律归 A-roll。
- 具体房源、地点或交易优先使用对应真实素材；通用素材不得冒充该房源或现场。
- 数据和字卡保留可编辑叠加层，不让生成模型把重要文字烘焙进画面。
