# Kevin Writing DNA

## 证据状态

当前版本是 v1 基线：依据历史 Top5 完整口播、本人发言证据、当前内容结构手册和团队语言标准整理。它足以约束写作，但不等同于 20 篇以上的完整 DNA 蒸馏。后续获得至少 20 篇完整脚本后，更新本文件并移除“种子版”标记。

## L1 语言 DNA

- 通篇称观众为“您”，本人用“我”，团队动作用“我们／团队”。
- 句子的主要任务是把因果、条件和判断讲顺，不以短句数量制造节奏。
- 常用路径：先出现具体事实或矛盾，再解释机制，接着拆人群/价位/区域，最后给条件和行动。
- 数据必须翻译成观众的选择、成本、风险或机会。
- 口语感来自主语清楚、逻辑直达和真实表达，不靠热词、口头禅或刻意自嘲。

## L2 结构 DNA

- 城市/社区比较：统一维度、真实缺点、适合谁。
- 市场分层：总判断 → 人群/价位/区域拆分 → 机制 → 改判信号。
- 买卖决策：冲突 → 初步判断 → 证据 → 两条路径的代价 → 条件式建议。
- 新闻政策：事件 → 传导链 → 受影响人群 → 行动。
- 高净值复杂交易：目标排序 → 路径比较 → 专业协作与时间节点。
- 豪宅社区：历史/稀缺 → 价值形成 → 风险 → 适配人群。
- 生活成本：具体账单/场景 → 月度结构 → 现金流与住房预算。

## L3 选题判断

优先选择能改变观众决策的事实、比较、政策、价格变化和市场分化。拒绝只靠名城、大数字和恐慌成立的题目。内容价值来自“谁会因此改变什么决定”。

## L4 素材策略

- 政府、监管、公司公告、MLS 和可靠研究优先。
- 公开事实、一线观察和个人判断分开表达。
- 数据要有日期、地区、口径和参照系。
- 团队案例只在能证明本段判断时出现，并遵守公开安全边界。

## L5 认知框架

Kevin 的核心不是预测单一涨跌，而是拆分人群、价位、区域、资金成本和持有条件；给条件式结论；指出建议何时失效。判断要能回答“对谁成立、在什么时间成立、什么信号会让判断改变”。

## L6 视觉 DNA

- 数据用可编辑图表和字卡，不截网页冒充结论。
- 城市比较用地图、边界、通勤和价格层次。
- 房源用真实空间、动线、材质和缺陷。
- B-roll 要承担举证、机制、比较或现场展示，不能只做装饰。

## 写前读取

1. 本文件。
2. 当前题材最接近的 2–5 篇 Kevin 本人原文。
3. 当期事实与项目案例边界。

## 更新协议

取得至少 20 篇完整内容后，按六个维度重新统计并更新：语言、结构、选题、素材、认知、视觉。每个结论保留至少两条来源证据，不把单条爆款当稳定风格。
