## 1. 样本结论

提供的近一年 Top 10 视频样本显示：

- 表现最强的入口是“具体地区/人群 + 高成本决策 + 反常识提醒”，例如城市上车选择、不同价位市场分裂、裁员与房价、年轻买家和高端隐私。
- Kevin 最有辨识度的部分不是给结论，而是把市场拆成城市、价位、购买力来源和持有条件，再逐层给策略。
- 城市比较类内容用统一维度和真实缺点帮助观众做 shortlist，具有较强长期搜索价值。
- 新闻、政策和 AI 主题只有连接到就业、股权、融资、库存与住房需求的传导链时，才形成专业价值。
- 高净值内容强调目标排序、多方案比较、提前规划与律师/CPA/贷款/产权团队协作，适合建立高端信任。
- 生活成本内容用餐厅、车辆、周末和月度预算等具体场景降低信息门槛，并自然回到住房现金流。
- 双人对谈通过追问、补充和轻微纠偏维持长视频节奏。

样本来自特定统计窗口，播放量不是永恒规律；自动转写也不是可直接复用的成稿。新选题仍要结合当前事实、受众需求与平台数据。

## 2. 标题与第一句话

### 硬规则

正式视频文字标题与视频第一句话逐字一致，包括语序和核心标点表达。先确定正式标题，再复制为首句。缩略图上的短文案可以不同，但不得制造正文没有兑现的新结论。

### 标题公式

- `地区 + 人群 + 明确决策`：湾区中产上车半岛，这三个城市怎么选？
- `表象 + 结构性反转`：湾区房价还在跌？真正分裂的是这三个价位。
- `事件 + 高焦虑问题`：科技公司又裁员，硅谷房价真的会崩吗？
- `反向警告 + 适用人群`：2026 年先别急着在硅谷买房，这三类人最容易后悔。
- `高端痛点 + 解决承诺`：硅谷买豪宅不想暴露隐私，交易前要先做哪四步？
- `具体案例 + 认知冲突`：刚毕业一年买 500 万美元豪宅，看的真是工资吗？
- `生活场景 + 收入门槛`：湾区普通家庭真实开销，到底赚多少才够花？

标题可以强，但不能出现正文无法证明的“必涨、必跌、第一、全部、内幕”。问句不等于可以不回答；正文必须给有条件的结论。

### 开头 30 秒

1. 原样说出标题。
2. 指出常见答案为什么太简单。
3. 明确本条要拆的维度和观众能拿走的决定。

示例骨架：

> 科技公司又裁员，硅谷房价真的会崩吗？先别急着把“裁员”和“房价”画等号。我们要分开看裁员发生在哪些岗位、库存有没有增加，以及刚需、改善和豪宅的购买力分别从哪里来。看完你会知道，自己该等的是价格，还是该先补现金流。

## 3. 七类内容骨架

### A. 城市或社区比较

1. 点出目标人群、预算和共同难题。
2. 先给比较坐标：通勤、教育、生活、房屋、土地、气候和预算。
3. 逐个城市按同一坐标比较，每个城市都讲一个优势和一个代价。
4. 给典型预算下能买到的产品，不虚构即时挂牌。
5. 按人群给 shortlist：谁适合哪个城市，谁不适合。
6. 中段征集观众的优先级，结尾引导做个性化选区评估。

不要写成城市百科或学区排名表。真正的价值是把“好城市”翻译成“对这类家庭合适的城市”。

### B. 市场分层分析

1. 用看似矛盾的市场现象开场。
2. 解释过去的结构和现在发生的变化。
3. 按刚需、改善和豪宅，或其他真实价位层级分别拆需求、库存和议价。
4. 连接就业、股权、利率或供给，但补齐传导链。
5. 分别给买家和卖家策略。
6. 说明接下来观察什么指标、什么时间点可能改变判断。

平均价格只能作为入口，不能替代结构分析。

### C. 买家或卖家决策

1. 以“我反而建议这类人先不要买/卖”建立反向钩子。
2. 承认行动看起来合理的原因。
3. 拆 3—4 个条件：时间线、现金流、安全垫、家庭计划、房屋适配或退出成本。
4. 用一个去标识化且来源明确的案例说明，不得编造。
5. 给“可以行动 / 应该等待 / 先补条件”的判断清单。
6. 结尾邀请提交预算、资产负债和时间线做具体评估。

不要用单一收入倍数或月供比例替所有家庭下结论；如引用经验值，要说明来源和适用边界。

### D. 新闻、政策或科技趋势解读

1. 说明事件、发生日期和可靠来源。
2. 解释新闻直接改变了什么，没有改变什么。
3. 画出传导链：就业/股权/融资/供给 → 住房需求或交易行为。
4. 指出核心湾区与外围、不同价位或不同人群的差异。
5. 给买家和卖家各一个行动建议。
6. 说明仍未知的变量和后续观察点。

法律与政策内容必须核验当前文本和生效状态；不要沿用旧视频里的数字或标题结论。

### E. 高净值与复杂交易

1. 从一个真实痛点开场：隐私、传承、融资、产权或时间压力。
2. 先确认目标排序：自住/投资、隐私、控制、税务、传承、贷款和退出。
3. 比较不同路径的功能与代价，不宣布万能方案。
4. 说明应在何时决策，尤其哪些事项必须在 closing 前完成。
5. 列出协作方及职责：房地产顾问、律师、CPA、贷款机构、产权/托管方。
6. 加清晰免责声明，并引导做多专业协同评估。

内容不泄露客户身份，也不以复杂结构暗示规避合法披露或监管。

### F. 豪宅社区深挖

1. 用历史、名人、稀缺土地或隐形门槛进入，但只使用可核验事实。
2. 解释社区价值形成机制，不只堆价格。
3. 展开建筑、土地、生活、教育、隐私或长期持有价值。
4. 明确至少两个风险，如洪水、历史保护、噪音、保险、维护或重建限制。
5. 区分“有钱能买”和“真正适合长期持有”。
6. 给适配人群和看房尽调重点。

### G. 湾区生活成本

1. 从一顿饭、一辆车、一次周末活动或一张账单开始。
2. 给具体价格与选择反差，保持轻松对话。
3. 扩展到月度类别：住房、饮食、交通、孩子、旅行和可选消费。
4. 区分必需支出与生活方式支出，不贩卖单一“够用收入线”。
5. 回到家庭现金流、安全垫和住房预算。
6. 让观众分享自己的版本，形成高质量评论。

## 4. 长视频节奏与平台适配

### YouTube 长视频

用户未指定时，按 12—16 分钟设计：

- 0:00—0:30：标题首句、矛盾和内容承诺。
- 0:30—2:00：必要背景与问题定义。
- 2:00—5:00：第一层机制或比较。
- 5:00—8:00：第二层分化，插入互动 CTA。
- 8:00—11:00：案例、反例或风险边界。
- 11:00—结尾：人群策略、结论和业务 CTA。

每 60—90 秒至少出现一次新问题、数字、反差、城市/价位切换、案例或搭档追问。章节之间用逻辑问题转场，不要机械说“接下来进入第二部分”。

### 短视频

默认 45—90 秒，只保留一个反常识判断、一条机制和一个行动。标题仍与第一句话一致；不强行塞两次 CTA，用户没有要求时保留一个主 CTA。

### 2—5 分钟中视频

保留一个主矛盾、两层机制或条件分支、一个收束判断。通常只设一个结尾 CTA；内容接近 5 分钟且自然出现互动节点时，可增加一个中段互动 CTA。不要为了满足长视频规则硬塞两次转化。

### 小红书或社交媒体图文

标题具体，前两三行兑现矛盾。用短段落和少量小标题呈现分层，结尾给一张条件清单或一个判断题。法律、市场和新闻内容保留日期与来源。

若用户给出明确平台、时长、字数或格式，以用户要求为准。

## 5. CTA 与最终检查

### 两类 CTA

- 互动 CTA：围绕区域、预算、时间线、价位或最大顾虑提一个具体问题。
- 业务 CTA：邀请已经进入决策阶段的人提供基本条件，做买卖、选区或高端复杂交易评估。

长视频至少出现两次 CTA，但不要连续堆动作。短内容按平台节奏保留一个主 CTA 即可。

### 最终检查

- 标题与第一句话逐字一致。
- 开头 30 秒内说清矛盾和观众收益。
- 事实有日期、来源或口径；判断没有伪装成事实。
- 用户要求非数据型框架时，至少列出发布前应核验的文件、报价或证据位，不用虚构数字填空。
- 至少拆了一组城市、价位、人群、时间线或风险层级。
- 每个专业词和关键数字都被翻译成决策含义。
- 新闻到房价之间存在完整传导链，而不是跳步。
- 同时写了机会、代价、反例或不确定性。
- 买家/卖家或不同人群获得了明确而不同的下一步。
- 高风险专业事项有边界说明和正确的协作方。
- 长视频两个 CTA 分散、自然、承接内容，没有假稀缺。
- 删除资讯播报、公关自夸、AI 排比、重复总结和销售恐吓。
