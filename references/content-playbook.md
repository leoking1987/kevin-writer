# Kevin 内容结构手册（社媒完播与多题材风味版）

本手册只做两件事：
1. **打破“什么主题都一个味道”**：按题材匹配完全不同的叙事口感与结构。
2. **植入真正的社媒完播引擎**：Cold Open（前 5 秒抓人）+ Re-Hook（中段钩子接力）+ 利落收口。

---

## 一、社媒完播引擎（所有视频通用）

### 1. 前 3–5 秒冷开场（4 种武器轮换，严禁复读标题）

| 开场武器 | 适用题材 | 示范（仅学结构，不抄事实） |
|---|---|---|
| **反常事实直击** | 市场数据、价格分化、冷门真相 | “同一个千万豪宅区，50 年老房两周抢光，全新大宅挂了三个月没人出价——您猜买家到底在躲什么？” |
| **二选一站队钩子** | 城市比较、买卖决策、换房取舍 | “手握 400 万，一边是通勤 10 分钟的 60 年老房，一边是开车多半小时的全新双层大院，您怎么选？” |
| **戳破主流盲区** | 科技/AI、政策解读、宏观趋势 | “盯着裁员新闻等硅谷房价跌的人，大概率会等错方向——因为撑住房价的钱，根本不是工资。” |
| **账单/场景直切** | 生活成本、持有成本、隐性坑 | “账面上看着赚了一百万，为什么真卖掉这套房，您到手的钱反而买不回隔壁同款？” |

### 2. 中段钩子接力（Re-Hook，防止观众中段划走）
每讲完一层（短视频 15–20 秒 / 长视频 45–90 秒），用极短一句活人转折把注意力甩进下一拍：
- **加码递进**：“如果只是多付这笔钱，其实咬咬牙还能忍——真正让人后悔的，是搬进去之后第二年冒出来的这件事。”
- **反转纠偏**：“听到这儿您可能觉得，那选 B 肯定稳了？先别急，把这笔账摊开，B 藏着一个更贵的坑。”
- **切入核心**：“刚才说的都是面子上的差别，下面这个数字，才真正决定您五年后能不能顺利出手。”

> 原则：每次 Re-Hook 后面**必须紧跟真干货/真反转**，严禁虚晃一枪说废话。

## 二、五大原生题材结构（彻底告别单一模板）

### 1. 侦探剥洋葱（适合：市场异动、价格分化、反常现象）
- **口感**：抽丝剥茧的破案感，越听越通透。
- **3–4 拍主骨**：
  1. **案发现场（冷开场）**：抛出一个违背直觉的真实市场反差。
  2. **推翻第一层假线索**：点出大多数人第一反应怎么解释，再用真实口径/分层拆穿为什么这个解释站不住。
  3. **挖出真正推手**：把市场拆到具体价位、城市或买家资金来源，讲透底层供需机制。
  4. **落回当下信号**：给 1–2 个观众自己就能盯住的观察指标，告诉他什么情况出现时局势会反转。

### 2. 多米诺传导链（适合：AI、科技大厂、裁员、利率与政策解读）
- **口感**：高维透视的局内人推演，干脆利落不掉书袋。
- **3–4 拍主骨**：
  1. **事件撞击点**：10 秒讲清发生了什么，直接戳破网上最离谱的过度解读。
  2. **三步传导链**：`政策/科技事件 → 谁的现金流/股权变了 → 哪一档房子的买卖动作先变`。
  3. **谁赢谁输**：只拆最受影响的 2 类人群或 2 个价位带，绝不面面俱到。
  4. **行动锚点**：给主要受众一条当下能用的应对动作，标清未知变量。

### 3. 摊牌算账（适合：买不买、卖不卖、换房、新房 vs 老房、豪宅尽调）
- **口感**：帮朋友算清最痛那笔隐性账的军师摊牌感。
- **3–4 拍主骨**：
  1. **二选一站队钩子**：先承认两个选项各自最诱人的地方，让观众觉得“你真懂我在纠结什么”。
  2. **摊开被忽略的那笔真账**：不只算挂牌价，把时间成本、持有开销、改造周期、转手买家池或税务/机会成本算到肉眼可见。
  3. **直接亮倾向 + 唯一例外**：给明确选择标准，再用一句话划出唯一改判条件（“除非您满足 X，否则别选 Y”）。

### 4. 真实生活对撞（适合：城市/社区对比、豪宅社区深挖）
- **口感**：不是房产百科，而是把两个地方的真实日子摆在一起撞出火花。
- **3–4 拍主骨**：
  1. **定位反差开场**：用一句话点破这两个地方在硅谷真正的阶层/生活分工。
  2. **挑 2–3 个最决定日常体感的维度对撞**：比如工作日早高峰通勤、周末生活圈、院子隐私与维护、社区硬伤（火险/噪音/审批/学区压力）——**只选真正拉得开差距的维度，不背 7 项全清单**。
  3. **人群对号入座**：谁搬过去会越住越香，谁搬过去半年就会后悔。

### 5. 松弛账本与现实反差（适合：湾区生活成本、科技圈生活、高净值日常）
- **口感**：放下专业西装，带轻松幽默和真实烟火气。
- **3–4 拍主骨**：
  1. **一顿饭/一张账单切入**：用极具体的日常数字开场。
  2. **把钱花在哪儿拆开看**：区分“被迫交的湾区税”和“可以自己掌控的生活方式选择”。
  3. **反差洞察**：为什么同样收入的两家人，一家每天紧绷、一家过得挺松弛？
  4. **互动收口**：把话筒交给评论区（“在湾区，您觉得最超出预期的一笔开销是什么？”）。

## 三、平台时长与结构适配

| 平台/体裁 | 目标篇幅 | 核心节奏要求 | 结尾动作 |
|---|---|---|---|
| **短视频 / Shorts / Reels / 视频号** | 45–90 秒（220–420 字） | 3 秒冷开场 → 15 秒破盲区 → 30 秒算清核心一笔账/机制 → 5 秒定调；**全程只讲 1 个点** | 强互动站队提问，或干脆金句收尾；原则上不塞硬 CTA |
| **中视频（YouTube / B站）** | 2–5 分钟（650–1,400 字） | 1 个主矛盾 + 2–3 拍递进，每 45 秒一个微反转 | 清晰判断标准 + 互动提问（或 1 个自然轻 CTA） |
| **YouTube 长视频** | 8–10 分钟（2,200–3,000 字） | Cold Open（15s）→ 3–4 大拍剥洋葱（每拍拆深机制/完整算账对照，每 60–90 秒设 Re-Hook）→ 痛快摊牌 | 1 个可执行标准 + 最多 1 个承接真实决策需求的轻 CTA |
| **小红书图文** | 350–700 字 | 强点击短标题（8–18 字）+ 首屏 3 行零废话破题 + 短段/对比清晰、一眼扫出干货 | 二选一/对号入座评论钩子，零中介催单感 |

## 四、高点击标题速查

公式：`具体对象/地点 + 反差事实或数字 + 切身得失/悬念`（8–20 字为主，拒绝纯抽象问句与“XX注意：”废话帽檐）。
- 决策摊牌：`400万冲Palo Alto老房，翻新根本不是最贵的`
- 市场反差：`大厂裁员潮，凭啥这几个价位的房子反而更难买？`
- 阶层/双城：`Palo Alto证明成功，Atherton为什么不用证明？`
- 隐性成本：`千万豪宅买大院子前，先算清这笔5年后的退出账`
- 详细数据规律按需见 [title-patterns-maggie.md](title-patterns-maggie.md)。
