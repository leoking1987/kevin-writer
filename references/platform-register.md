# Kevin 平台语域

语域改变的是**信息顺序、钩子密度、呼吸节奏和收口方式**，不是只删字数或加 emoji。写前先定平台。

## 1. 短视频 / Shorts / Reels / 视频号 / 抖音（`short-social`）
- **篇幅**：45–90 秒（220–420 字）。
- **节奏**：前 3 秒冷开场直刺盲区或抛二选一；全片只打穿 **1 个核心冲突 + 1 条底层账/机制**；每 15–20 秒必须推进一层新信息。
- **口吻**：更干脆、更直接、少铺垫；允许一句带锋芒的神比喻或轻吐槽。
- **收口**：利落定论 + 低门槛互动问题（站队/评论），原则上不硬塞营销 CTA。

## 2. YouTube 中 / 长视频（`studio-explain` / `decision-conversation`）
- **篇幅**：中视频 2–5 分钟（650–1,400 字）；长视频 8–10 分钟（2,200–3,000 字）。
- **节奏**：Cold Open（前 15 秒钩住但不剧透底牌）→ 3–4 个单向递进大拍（每 45–90 秒带一次 Re-Hook）→ 痛快摊牌 + 唯一例外。
- **口吻**：像顶级顾问面对面聊真话——专业但不学术、克制但不冷冰冰、有松紧呼吸。
- **收口**：1–2 句可执行标准；确有真实业务承接时最多留 1 个自然轻 CTA。

## 3. 小红书图文（`xhs-post`）
- **篇幅**：350–700 字，适合手机一屏扫读。
- **节奏**：强点击短标题（8–18 字）+ 首屏前三行直接破题（零背景铺垫）+ 短段落配清晰小标题/对比锚点，一眼扫完就能带走核心判断。
- **口吻**：去中介推销味、去端水免责腔；用同路人/一线局内人的口吻直接说干货，结尾用二选一或对号入座拉互动。

## 4. 正式说明与书面材料（`formal-record`）
- 保留必要术语、归因、日期口径与责任主体；句子仍要清晰直接、少堆叠修饰，不把条件判断改成口号。

## 跨平台改写检查
同一主题从 YouTube 长视频转成短视频或小红书时，**必须重选最抓人的单一冲突切口、重写前 3 秒冷开场和结尾互动**，严禁把长稿机械缩写成“摘要版”。
